Optional: put font files here so the app looks the same with no internet.
Download each from fonts.google.com (Download family), then copy the .ttf and rename it:
  pixel.ttf     Silkscreen (Bold or Regular)   title bar and buttons
  heading.ttf   Syne                            reference pill
  verse.ttf     Newsreader                      verse text
  ui.ttf        Instrument Sans                 operator window
  elegant.ttf   Playfair Display                'Elegant' font choice
  modern.ttf    Montserrat                      'Modern' font choice
Missing files are fine: the app falls back to ordinary system fonts.
